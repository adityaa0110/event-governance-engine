# Run on YOUR laptop (for Vibeathon)

Cloud Agent `127.0.0.1` is not your laptop. For the live demo, run locally:

```bash
# 1) Unzip / copy this folder to your machine, then:
cd event-governance-engine
chmod +x scripts/*.sh

# 2) Backend
./scripts/start-backend.sh

# 3) Frontend (new terminal)
./scripts/start-frontend.sh

# 4) Open
# http://127.0.0.1:5174
```

Optional: open `docs/slides.html` in Chrome for the pitch deck.
Demo script: `PRESENTATION.md`
